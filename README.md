# Utryckning Härnösand

Övningsspel för räddningstjänsten: lär dig gator, områden och orter i Härnösand.

**Spela:** https://jackenilsson.github.io/utryckning/

Installera som app: öppna länken i Safari (iPhone) och välj Dela → Lägg till på hemskärmen. På Android frågar Chrome om du vill installera.
